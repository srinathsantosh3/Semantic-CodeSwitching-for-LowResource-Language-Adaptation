# Dataset Resources & URLs

This document contains the verified URLs, official repositories, and publication links for all benchmark datasets used in the study.

---

## 1. Primary Benchmark Datasets

### **MTOP** (Multilingual Task-Oriented Semantic Parsing)
* **Dataset (Hugging Face):** [mteb/mtop_domain](https://huggingface.co/datasets/mteb/mtop_domain)
* **Paper (EACL 2021):** [https://aclanthology.org/2021.eacl-main.257](https://aclanthology.org/2021.eacl-main.257)
* **Description:** Multilingual semantic parsing benchmark across 6 languages covering intent classification and slot filling.

---

### **PAXQA** (Pairwise/Parallel Cross-Lingual Question Answering)
* **Code & Data Repository:** [manestay/paxqa](https://github.com/manestay/paxqa)
* **Paper (Findings of EMNLP 2023):** [https://aclanthology.org/2023.findings-emnlp.32](https://aclanthology.org/2023.findings-emnlp.32)
* **Description:** Cross-lingual question answering dataset designed for generating parallel training examples at scale.

---

### **xGQA** (Cross-Lingual Visual Question Answering)
* **Official Code Repository:** [adapter-hub/xGQA](https://github.com/adapter-hub/xGQA)
* **Dataset (Hugging Face):** [floschne/xgqa](https://huggingface.co/datasets/floschne/xgqa)
* **Paper (ACL 2022):** [https://aclanthology.org/2022.acl-long.174](https://aclanthology.org/2022.acl-long.174)
* **Description:** Multimodal, cross-lingual dataset for visual question answering across 7 diverse languages.

---

### **XNLI** (Cross-Lingual Natural Language Inference)
* **Dataset (Hugging Face):** [facebook/xnli](https://huggingface.co/datasets/facebook/xnli)
* **Code Repository:** [facebookresearch/XNLI](https://github.com/facebookresearch/XNLI)
* **Paper (EMNLP 2018):** [https://aclanthology.org/D18-1269](https://aclanthology.org/D18-1269)
* **Description:** Benchmark evaluation corpus for cross-lingual language understanding across 15 languages.

---

### **GBC1M** (Graph-Based Captioning 1M)
* **Dataset (Hugging Face):** [graph-based-captions/GBC1M](https://huggingface.co/datasets/graph-based-captions/GBC1M)
* **Code Repository (Apple ML):** [apple/ml-gbc](https://github.com/apple/ml-gbc)
* **Description:** Large-scale dataset of 1 million graph-aligned image-caption pairs for vision-language pre-training.

---

### **SCB-MT-EN-TH-2020** (English-Thai Parallel Corpus)
* **Dataset (Hugging Face):** [airesearch/scb_mt_enth_2020](https://huggingface.co/datasets/airesearch/scb_mt_enth_2020)
* **GitHub Repository:** [vistec-AI/dataset-releases](https://github.com/vistec-AI/dataset-releases)
* **Journal Publication (LRE 2022):** [Springer Link](https://link.springer.com/article/10.1007/s10579-022-09605-2)
* **Description:** Large-scale parallel corpus containing over 1 million English-Thai translation pairs.
